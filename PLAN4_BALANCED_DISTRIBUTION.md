### 3. PLAN 4 - DISTRIBUCIÓN EXACTA Y EQUILIBRADA

El Plan 4 es el **MÁS COMPLETO**:
- 1 desayuno + 2 main meals = **3 comidas al día**
- Calcula las necesidades EXACTAS del cliente
- Distribuye los macros de manera EQUILIBRADA

#### Cómo Funciona el Plan 4:

**Paso 1: Calcular Necesidades Diarias**
```
Datos del cliente:
- Edad: 30 años
- Altura: 175 cm
- Peso: 75 kg
- Sexo: Masculino
- Actividad: Moderada

↓ Se calcula TMB (BMR)
TMB = 1,750 kcal

↓ Se calcula TDEE
TDEE = TMB × Factor actividad
TDEE = 1,750 × 1.55 = 2,713 kcal

↓ Se ajusta según objetivo
Objetivo: Mantener peso
Calorías objetivo = 2,713 kcal/día
```

**Paso 2: Calcular Macros Diarios**
```
Proteína diaria = basado en peso y objetivo
Ejemplo: 120g de proteína/día

Grasas = 25% de las calorías
= (2,713 × 0.25) / 9 = 75g/día

Carbohidratos = calorías restantes
= (2,713 - (120×4) - (75×9)) / 4
= (2,713 - 480 - 675) / 4
= 390g/día
```

**Paso 3: Distribuir EQUILIBRADAMENTE en 3 Comidas**

❌ **MAL - Distribución Desbalanceada:**
```
Desayuno:  10g proteína  ← MUY POCO
Main 1:    40g proteína  ← OK
Main 2:    40g proteína  ← OK
Total:     90g           ← Suma mal
```

✅ **BIEN - Distribución Equilibrada:**
```
Si el cliente necesita 120g proteína/día:

Desayuno:  40g proteína, 25g grasa, 130g carbos = 904 kcal
Main 1:    40g proteína, 25g grasa, 130g carbos = 904 kcal
Main 2:    40g proteína, 25g grasa, 130g carbos = 905 kcal
Total:     120g         75g         390g         2,713 kcal ✅

Distribución: 40g, 40g, 40g ✅ EQUILIBRADO
```

✅ **BIEN - Otro Ejemplo (90g proteína):**
```
Si el cliente necesita 90g proteína/día:

Desayuno:  30g proteína
Main 1:    30g proteína
Main 2:    30g proteína
Total:     90g ✅

Distribución: 30g, 30g, 30g ✅ EQUILIBRADO
```

### 5. MATEMÁTICA CORRECTA

**Fórmula de Calorías:**
```
Calorías = (Proteína × 4) + (Carbos × 4) + (Grasa × 9)
```

**Ejemplo:**
```
Proteína: 40g × 4 = 160 kcal
Carbos:   130g × 4 = 520 kcal
Grasa:    25g × 9 = 225 kcal
━━━━━━━━━━━━━━━━━━━━━━━━━
Total:    905 kcal ✅
```

### 6. REGLA DE NEGOCIO

**Máximo 40g de proteína por comida**

¿Por qué?
- Más de 40g = cuesta más preparar
- 40g es óptimo para absorción
- Mantiene rentabilidad del negocio

Ejemplos:
```
Cliente necesita 150g proteína/día:
150g / 3 comidas = 50g por comida
↓ Se ajusta a máximo
40g, 40g, 40g = 120g total
(Se limita a lo rentable)

Cliente necesita 90g proteína/día:
90g / 3 comidas = 30g por comida ✅
30g, 30g, 30g = 90g total
(Dentro del rango óptimo)
```
